# Kathana — Official Website

**Kathana** is a screenwriting application by Jagnaam Pictures.

This repository contains the official Kathana website and online user guide.

🌐 **Official Website:** https://jagnaampictures.github.io/kathana-website/

## About Kathana

Kathana is built for screenwriters who want a dedicated space to write and develop their stories.

Our goal is to make screenwriting accessible while prioritizing writers' control over their work.

## What's Available Here?

- Official Kathana website
- Online user guide and documentation
- Public information about Kathana
- Links to official releases and resources, when available

## Project Philosophy

Kathana follows an offline-first, local-first approach to screenwriting. Writers' screenplay files are intended to remain under their control on their own devices.

Refer to the official documentation and privacy policy for details about the features available in each release.
